# Language Basics COBOL

## Contributing

The test corpus is generated from a curated set of permissively licensed COBOL repositories, including:

- shamrice/COBOL-Examples
- exercism/cobol
- aws-samples/aws-mainframe-modernization-carddemo
- uwol/proleap-cobol-parser

```sh
git clone git@github.com:lvce-editor/language-basics-cobol.git &&
cd language-basics-cobol &&
npm ci &&
npm run update-test-cases &&
npm test
```
